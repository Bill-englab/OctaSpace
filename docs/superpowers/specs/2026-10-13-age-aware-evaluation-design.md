# OctaSpace：基于年龄与家庭目标的成长评估

日期：2026-10-13
状态：待用户审阅

## 目标与已确认的评估口径

评估是家长主动触发的独立功能。日常记录继续保持随手记、有什么记什么；评估不得评价记录是否及时、连续或足够丰富。报告要结合孩子的准确月龄、适龄发展参照、家庭目标、长期基线、进度目标和已有观察，判断家庭当前的培养方向及下一步的差距。五个角度是德（社会情绪）、智（语言与认知）、体（健康与动作）、美（艺术感受与表达）、劳（生活自理与参与）；它们是给家长看的组织方式，不是五项标准化分数。

用户已认可的表达方式：先给有依据的总体判断；逐维解释年龄参照、孩子表现与目标差距；把未知项留白；推荐不超过三个具体、符合兴趣的活动；说明家长如何引导以及下次看什么变化。记录少时照常利用基础资料评估，不能将“未记录”解释为“未做”或能力不足。

## 方案取舍

| 方案 | 优点 | 限制 |
| --- | --- | --- |
| 仅扩写模型提示词 | 代码改动最少 | 年龄参照依赖模型记忆，来源与措辞不可控 |
| **内置经核对的年龄参照＋结构化评估提示词（采用）** | 可核对参照来源；报告结构稳定；便于逐条追溯 | 需要维护小型参照库和报告版本 |
| 每次评估实时联网查资料 | 可获取新资料 | 速度、来源质量和家庭隐私边界不稳定；不适合当前本地应用 |

## 年龄参照

服务端保存一份经过人工核对、版本化的简短参照库，初版覆盖孩子当前所处的 4 岁阶段。来源：

- 教育部《3–6岁儿童学习与发展指南》：健康、语言、社会、科学、艺术五领域；3–4 岁及 4–5 岁年龄段的典型表现与教育建议。来源：<https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2015nztzl/xueqianjiaoyu/yaowen/202104/W020210820338905908083.pdf>。
- CDC 的 4 岁发展观察项目：社会情绪、语言沟通、认知、身体动作及生活自理相关例子。来源：<https://www.cdc.gov/act-early/milestones/4-years.html>。

每个参照条目存 `id`、维度、适用年龄段、通俗转述、来源 URL 和版本。评估日期决定月龄。对于刚满 4 岁的孩子，以“4 岁常见表现”作为当前观察参照，以教育部“4–5 岁阶段末期表现”作为未来方向，不将后者写成当前必须达到的清单。教育部五领域映射到产品的德智体美劳；“劳”主要来自生活自理和参与家务。参照库不是诊断或考试标准，不产生百分位或分数。孩子年龄超出参照库时，不套用不合适的年龄段；页面说明尚无该年龄的参照并保留基于资料的目标讨论。

参照库至少覆盖：社会互动、同理心与情绪表达；日常语言与讲述、提问和解决问题；大动作、手部动作与健康习惯；音乐节奏、艺术兴趣与自主表达；穿脱、整理及力所能及的家庭参与。英语、RAZ 级别、识字量和具体运动技能只与家庭自定目标比较，不伪装成权威年龄标准。五维中的每个条目都要能追溯到教育部指南或 CDC，而不是由模型即兴补齐。

参照库只包含准确转述和链接，不复制整份指南；原始来源可在评估报告中查看。参照更新需要版本变更，历史报告保留生成时的参照版本。

## 输入与上下文

1. 孩子资料总是纳入：出生日期、兴趣、家庭关注方向、已有基础、背景备注。
2. 活跃的进度目标及其最新状态总是纳入；即使本次日期范围没有新观察，也让模型知道家庭目标。历史进度按目标串联，保留首个与最近的有依据观察。
3. 家长选择的日期范围用于近期活动和日记；紧邻的等长时段仅用于**有证据时**说明变化。历史资料可以提供较早的里程碑和长期背景，不把空白时段理解成活动中断。
4. 原始记录数量很多时，保留可溯源的摘要和原始 ID；压缩过程只提取事实、孩子原话和日期，不预先评价。
5. 有生日和至少一项家庭目标、基线或进度目标时，即便所选时段无记录也可生成“基础资料版评估”。既无基础资料又无相关记录时，提示先补充孩子资料；不输出空泛报告。
6. 明确给模型标注三类事实：`年龄参照`、`家长填写的长期基线与目标`、`日期范围内的具体观察`。不能把家长估计（例如理解比例）呈现为测验结果。

`focus` 是自由文本，已有进度目标也可能很宽泛。模型须原样理解家长意图，不能替家长编造量化目标；若目标无法判断进展，则在报告中提出一个澄清问题。此设计不增加每日记录的必填项。

## 评估模型指令

服务端提供静态系统指令，注入年龄参照与上下文后请求 JSON。指令核心如下；实际实现可分段组织，但规则语义必须保持。

```text
你是面向家长的学龄前儿童成长与家庭培养顾问。评估孩子当前已知的发展表现、家庭目标的适龄性与培养方式、从当前能力到目标的差距，以及未来 2–4 周最值得尝试的活动。

先计算评估日期的准确月龄。区分当前年龄常见表现与下一年龄段末期方向。只使用提供的、带编号的年龄参照；不要凭记忆添加某阅读级别、识字量、英语熟练度或运动项目的年龄常模。五维是德、智、体、美、劳，但不打分，不给整体“优秀/落后”标签。

资料分三层：权威年龄参照、家长长期资料与目标、具体记录。每项关键结论必须说明依据及确定程度。近期没有某类记录意味着“尚不知道”，不是“孩子没做”或“投入不足”。记录是随手写的，不评价记录频率、完整性或家长是否勤奋。接触、模仿、跟读、理解、掌握、自发使用是不同表现，不得混同。没有前期证据时不编造趋势。

对五个维度分别写：年龄参照、已知表现、家庭目标与差距、当前判断（有依据/暂定/待了解）、需要补充的一个问题。还要单独评价家庭目标与培养方式：哪些方向适合孩子及其兴趣，哪些目标可能过密、过窄或缺乏可观察进阶。判断应直接但温和。

给出一句话总体判断、最多三个有优先级的未来 2–4 周行动。每个行动写明为什么选、如何在孩子喜欢的游戏或生活场景中开展、家长能说什么或做什么、出现什么变化说明方向有效、孩子不感兴趣时如何调整。不要为了填满五维而增加课程、打卡或训练。给出最多三个下次回顾问题。

不做医学诊断，不使用没有依据的发育分数。如资料显示技能倒退或家长有发展担忧，建议与专业人员讨论。请返回约定 JSON 结构；不要输出一整段报告文字，也不要输出 Markdown 代码块。
```

## 结构化报告与校验

新报告采用版本化 JSON；字段为 `summary`、`familyPlan`、`dimensions[5]`、`gaps[]`、`actions[1..3]`、`followUpQuestions[0..3]`、`limits`、`referenceVersion`。每个维度包含固定 ID、标题、年龄参照 ID、表现、目标差距、判断状态、证据来源和待了解问题。每个行动包含优先级、理由、玩法/生活场景、家长引导、观察信号、调整办法。证据来源为记录 ID、资料字段名或年龄参照 ID；仅通过服务端白名单校验后才可显示链接。

服务端校验 JSON 可解析、五维齐全、行动数量与字段、引用 ID 有效。无效报告不保存并显示可操作的重试错误；不得退化为截断的原文。报告与生成时的参照版本、模型和日期范围一同保存为快照。旧版纯文字报告继续可读，显示“旧版报告”；不会自动重写或删改。

存储上保留现有 `evaluations.content` 供旧报告与备份兼容，新增可空的结构化报告字段及参照版本字段。读取接口依据字段是否存在返回新版或旧版报告；旧备份仍可导入，新备份保留两种报告。年龄参照加载、上下文整理、模型提示词、响应校验、页面渲染分别有明确职责，避免把所有逻辑堆进一个组件或一个提示词字符串。

## 评估页面

- 页面顶部：选择评估时段、显示评估日期对应月龄、主动生成按钮。文案说明记录可随手记，评估同时参考长期资料和目标。
- 新报告首先呈现一张“总体判断”卡，含一句核心结论和最重要的培养建议；旁边有“家庭目标与当前差距”摘要。
- 下方五维卡片，桌面两列、手机单列。每张卡只展示结论、年龄参照、已有表现和状态；展开后看证据、目标差距及待了解问题。未知状态不画灰色低分柱。
- 再下方是最多三张行动卡：为什么、怎么玩、家长怎么引导、看什么信号、若不喜欢怎么改。每张卡有明显优先级和可读的标题。
- 页尾显示三个下次回顾问题、判断边界及年龄参照来源。证据链接贴近对应结论；不把所有关联记录堆在报告末尾。
- 已有旧报告继续以原文呈现，但采用可读的段落排版。新报告的文字不能以 `white-space: pre-wrap` 的大段原文充当最终界面。
- 保持现有清爽绿白视觉、页面宽度不设上限；不引入雷达评分。AI 对话页面仍可围绕报告继续提问，不在本次改动中重做聊天。

## 错误、隐私与验证

- 缺少生日时提示填写；缺少目标与基线时报告可说明未知，但若连记录也没有则不给空泛评估。
- MaaS 返回截断、超时、无效 JSON 或缺失必要维度时，不保存半成品；保留所选日期便于重试。
- 凭据仍只在本地服务端配置。用户主动生成时才把当前孩子资料、目标、相关记录和短版年龄参照发给已配置 MaaS。参照库和提示词不得写入真实孩子资料或密钥；仓库中的测试资料全部虚构。
- 用模拟 MaaS 响应验证：年龄边界、五维齐全、未记录不被误判为不足、基线与观察分层、无记录但有基线能生成、虚假引用被剔除、旧报告兼容、无效报告不保存。
- 用当前配置的真实模型进行一次手动端到端验证，检查内容与 UI；验证期间不改动旧报告。真实模型的表现仍可能有波动，结构与引用由服务端校验。

## 完成标准

家长主动生成的报告能回答“孩子当前哪些方面已有可观察优势、哪些尚不清楚、家庭目标是否适龄、最值得投入的下一步是什么”。报告可在五维卡片与行动卡中阅读，能看到判断依据；不会将随手记录的不连续性当成孩子或家长的问题。
