# 孩子成长日记：首版设计

日期：2026-10-12
状态：待用户审阅

## 目标与范围

本项目是一个由家庭在本机运行、可通过局域网访问的成长记录网页。**记录是主体**：家人每天按活动类型快速写下做了什么、进度和状态，也能自由写日记。家长需要回顾时，主动生成 AI 评估；另有独立的 AI 对话页面，允许围绕孩子的基础资料及指定时间范围内的记录提问。

首版支持一名孩子、一套家庭共享记录。桌面网页采用用户选定的 **C「成长时间线」** 原型；手机布局保留相同信息架构，调整为单列和便于触摸的大按钮。页面容器不设置最大宽度，大屏充分利用空间。

### 首版包含

- 孩子资料：生日、称呼、兴趣、家庭关注方向、已有基础情况和自由备注。年龄按记录或评估日期计算。
- 可自定义活动分类。初始分类包含英语、体育、音乐、认知与动手、社交情绪、日常生活；每个分类都能从首页一键新增记录。
- 活动记录：发生时间、分类、内容；可选时长、心情、状态、标签、照片或短视频、关联进度目标。英语分类还可选填新词汇、句型和主动表达情况。
- 每日自由日记：记录事件、孩子原话、感受及家人的观察；一日可写多则，可关联当天活动或媒体。
- 进度目标与观察：为具体目标记录“初次尝试／练习中／能独立完成”、发生日期和证据。里程碑可自定义；预设项目只是可编辑的记录示例，不作为年龄达标标准。
- 成长页面：活动热力图、分类分布、目标进度及能力维度雷达。雷达数值表示**已记录目标的完成情况**，同时显示目标数量及证据，不能解释为儿童发育的标准化评分。
- 手动触发的 AI 评估：多维当前观察、与先前记录的变化、证据与记录空白、接下来 2–4 周的活动建议和观察点。保存完成的报告供回看。
- 独立 AI 对话：可选择时间范围，也可识别问题中的相对时间；回答能链接到引用的记录。聊天历史保存在本地。
- MaaS 设置：支持 OpenAI 兼容的 Chat Completions 消息格式与 Anthropic Messages 格式，可填服务地址、模型、密钥和连接参数，并测试连接。
- 本地数据备份与恢复：导出资料、数据库和媒体的完整备份，恢复前显示将覆盖的内容。

### 首版不包含

- 语音转文字。首版以大按钮和文字为主；将来在确定语音服务与手机浏览器方案后加入。
- 与既有英语互动项目的自动同步。先在英语记录中保存词汇、句型和表达数据；获得旧项目的实际接口后再对接。
- 自动定时生成报告、推送提醒、多人角色权限或多名孩子资料。
- 医学诊断、发育迟缓筛查结论或按年龄计算的“正常／异常”分数。

## 方案选择

采用一个本地网页服务、一个本地 SQLite 数据库和本地媒体目录。服务同时提供网页、数据接口和 MaaS 代理。这样电脑与局域网中的手机共享数据，MaaS 密钥保留在主机侧。

浏览器单机存储会让多设备记录分散；直接构建复杂的向量检索与多 Agent 工作流会增加首版的运维与验证难度。当前的日期、分类、目标和记录关系足以支持可解释的检索，后续再根据真实数据量决定是否增加语义索引。

## 界面与交互

### 今日记录：C「成长时间线」

桌面左侧是“今天、活动分类、成长进度、AI 评估、AI 对话、设置”。主区顶部显示日期及新增记录按钮；其下可按分类筛选时间线。时间线卡片显示活动、发生时间、简短观察和关联进度。右侧是自由日记、状态与进度的入口；“生成 AI 评估”是明确的辅助入口，不显示未经请求生成的结论。

视觉沿用 C 原型的清新绿、暖白底、柔和边框与大圆角。阅读文字有足够对比度，卡片与记录密度适合桌面。手机改为底部导航、单列时间线和固定的快速新增入口。所有核心操作可以用触摸完成。

### 快速记录

1. 点选英语、体育、音乐等分类，直接打开对应记录表单。
2. 填一句发生的事即可保存；时间默认当前时间，其他字段可选。
3. 需要时补充目标进度、孩子原话、心情、媒体或分类专属字段。
4. 保存后立即出现在当天时间线，可编辑或删除。删除媒体前明确确认。

自由日记不要求先选分类。可将一篇日记关联多条活动，保持叙事完整。以后若增加 MaaS 辅助解析口语记录，解析结果必须先供用户确认再保存。

### 成长与评估

成长页的数据图表直接来自记录，展示日期范围和样本数量。活动热力图按每天记录的活动类别数量着色；雷达按维度显示已建立目标中达到“能独立完成”的比例，旁边给出分子、分母和关联目标。记录稀少时显示“资料不足”，不绘制误导性的高低能力判断。

AI 评估页面先选择评估时段，默认最近 30 天，并展示即将使用的记录范围及数量。历史比较采用紧邻的等长前一时段；更长期的目标进展可作为补充。用户点击生成后，报告按“当前观察、进度变化、需要继续观察、接下来 2–4 周可尝试的活动、下次回顾时看什么”组织。每项结论要指向具体记录；没有依据时明确说明。生成完成后保存快照，后续记录变化不会静默改写旧报告。

### AI 对话

聊天页独立于评估页。用户可手动指定时间范围；若问题明确写出“上周”等范围，以问题为准并在发送前显示解析出的日期。系统展示本次纳入的记录数量。回答将观察事实、推断和建议分开，并提供可打开的来源记录。问题、回答、使用的模型和时间范围进入本地聊天历史。模型不可用时保留问题，允许重试。

## 数据与模块边界

| 模块 | 职责 | 主要数据 |
| --- | --- | --- |
| 孩子资料 | 保存基础信息，按日期计算年龄 | `child_profile` |
| 记录 | 分类、活动、自由日记与关联 | `categories`, `activities`, `diary_entries`, `diary_activity_links` |
| 进度 | 目标、里程碑、状态变化和证据 | `progress_goals`, `progress_observations` |
| 媒体 | 校验、保存和授权读取文件 | `media_assets` 与本地文件 |
| 统计 | 计算图表所需的可复核汇总 | 由记录与进度生成，不另存模型评分 |
| 上下文检索 | 根据日期、类别、目标取得记录，控制上下文体量 | 引用记录 ID 的上下文包 |
| MaaS 适配 | 将统一请求映射到 OpenAI 兼容或 Anthropic 协议 | 主机侧配置与凭据 |
| 对话 | 管理聊天、调用检索和适配器 | `chat_sessions`, `chat_messages` |
| 评估 | 生成并保存带依据的报告快照 | `evaluations` |

时间戳以带时区的标准格式保存，界面按家庭所在时区显示；日记另有明确的本地日期，避免午夜附近的记录落到错误的一天。记录 ID 稳定，供报告和聊天回答引用。媒体只存文件路径与元数据，数据库不存二进制大文件。

### MaaS 统一接口

服务端内部使用统一的“系统指令、历史消息、当前问题、输出配置”请求。OpenAI 兼容适配器映射到消息数组及对应结果；Anthropic 适配器将系统指令放在顶层 `system`，处理 `messages`、`max_tokens` 和内容块结果。两者分别处理认证、流式事件、限流与错误响应，不能仅替换 URL。新增服务商时只增加适配器，不改变记录、评估或聊天模块。

MaaS 配置页仅在主机电脑的本机地址允许修改密钥；密钥不写入网页本地存储、不出现在读取配置的响应中。局域网访问需要家庭访问码，媒体接口也要求同一会话。用户可以关闭局域网监听，仅在本机访问。发送到 MaaS 的信息只包含所选时间范围内的资料和记录；界面明确显示此范围。

## 评估与对话的数据流

1. 接收用户问题或评估时段，确定孩子在该时段的年龄与时间范围。
2. 从 SQLite 检索相关活动、日记、目标状态及此前等长时段的比较资料。
3. 计算类别数量、目标状态变化和记录覆盖情况；将原始记录 ID 与日期带入上下文。
4. 当记录超出模型上下文预算时，分批生成带原始 ID 的中间摘要，展示实际覆盖范围；不静默省略记录。
5. 通过选定的 MaaS 适配器生成回答。系统指令要求区分观察、推断与建议，不编造没有记录支持的事实。
6. 校验引用 ID 是否属于本次检索结果；无法对应的引用不显示为来源。只在回答完整时保存评估报告。

## 错误处理与隐私

- 记录保存失败：保留输入内容，提示重试；媒体上传失败不应抹掉文字记录。
- MaaS 未配置、认证失败、超时或限流：显示可操作的状态，不显示虚构评估；保留问题和选择的时间范围。
- 记录不足：报告明确写出覆盖天数和记录数，避免把缺少记录解读成缺少活动或能力。
- 媒体只接受允许的图片与短视频类型，限制大小，拒绝不安全文件名；访问需登录。
- 家庭访问码保护局域网入口；MaaS 设置限制在主机本机访问。首版不主动向第三方发送数据，只有用户触发对话、评估或连接测试时调用配置的 MaaS。
- 备份包含敏感家庭资料，导出时提示保管位置；备份不包含 MaaS 密钥。

## 验证标准

- 电脑和局域网手机能看到同一条新记录；断开 MaaS 时仍可正常记录、查看和编辑。
- 英语、体育、音乐及自定义分类均能快速新增活动；日记和进度目标可独立编辑并正确关联。
- 日期范围跨月、跨年及午夜附近时，检索、热力图和报告覆盖范围正确。
- 图表的数值能回溯到记录和目标，不把记录稀少误写成能力低。
- 使用模拟 MaaS 响应验证两种协议的请求结构、认证失败、超时与限流；真实凭据仅由用户在设置中提供。
- AI 回答的来源链接只指向本次纳入的真实记录；旧评估报告在新记录加入后保持原样。
- 桌面与手机分别检查主要流程、可读性、触摸尺寸和无最大宽度限制的布局。

## 完成定义

家人可以连续多天使用网页记录活动、状态、进度与日记；家长能随时从独立页面与 MaaS 对话，并主动生成能追溯记录依据的阶段性评估。无需 MaaS 时，记录、图表和历史浏览仍可使用。
