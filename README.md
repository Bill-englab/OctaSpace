# OctaSpace

一个运行在自己电脑上的家庭成长记录网页。首页以活动和日记为主；AI 评估由你主动触发，AI 对话可随时读取指定时间范围内的记录。

## 开始使用

需要 Node.js 24 或更新版本、pnpm。Windows 可双击 `start.cmd`；也可以在项目目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm build
node server/index.js
```

浏览器打开 `http://localhost:4173`，无需登录。记录保存在项目下的 `data/`，不会提交到 Git。

在「活动类型」里可以给英语、体育、音乐等类型添加项目，例如英语下的 RAZ 和口语。记录活动时可选一个项目，也可以直接点击项目进行快捷记录。

进入「设置」填写孩子的基础信息和 MaaS。支持 OpenAI 兼容接口与 Anthropic Messages 接口；API 密钥仅保存在本机服务端数据里，网页只显示是否已配置。设置里的「测试连接」只发送一条不含孩子资料的测试消息。点击首页「和 AI 聊聊」或左侧「AI 对话」，选择参考记录的日期范围，在底部输入问题并发送；回答会列出引用的原始记录。需要阶段总结时，进入「AI 评估」主动生成报告。

## 局域网访问

在运行服务的电脑上设置 `HOST=0.0.0.0` 后启动。家里的其他设备访问 `http://电脑的局域网IP:4173`。MaaS 密钥的新增和修改只允许在运行服务的电脑上进行。由于页面无需登录，局域网内能访问这个地址的设备都能查看记录；请只在可信任的家庭网络中开放端口，不要直接暴露到公网。

```powershell
$env:HOST='0.0.0.0'
node server/index.js
```

## 数据与备份

活动、项目、日记、成长目标、聊天和评估都在本机 `data/` 下。设置页可以下载和导入完整备份；备份不包含 MaaS 密钥。旧版备份仍可导入。导入会替换当前记录，请先下载一份现有备份。旧版备份中已有的媒体附件会随备份保留，但网页不再展示或上传图片和视频。

## 开发

```powershell
pnpm dev:server
pnpm dev:web
pnpm test
pnpm build
```

本地开发时 Vite 默认提供前端页面，`/api` 请求代理到 4173 端口。正式使用只需构建并启动服务端。
